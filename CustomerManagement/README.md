# Customer & Transaction Management API

A backend RESTful API developed using **C# and ASP.NET Core Web API**.

The project focuses on practical backend development concepts including **C#, REST APIs, authentication, customer management, transaction processing, database operations, and Swagger/OpenAPI**.

---

##  Project Overview

The Customer & Transaction Management API provides backend services for managing customers and their financial transactions.

The system includes:

- User registration and login
- Token-based authentication
- Customer management
- Deposit management
- Withdrawal management
- Transaction history
- Total deposit calculation
- Total withdrawal calculation
- Customer-specific transaction details
- Swagger API documentation and testing
